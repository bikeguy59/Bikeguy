Welcome! This is the first post on my new blog.

## Writing a new post

Add a Markdown file to the `_posts` folder named `YYYY-MM-DD-title.md`, starting
with front matter like this:

```yaml
---
layout: post
title: "My Ride Today"
date: 2026-10-04 08:00:00 -0400
categories: rides
---
```

Then write the post in Markdown below it. Commit and push, and GitHub Pages
rebuilds the site.
